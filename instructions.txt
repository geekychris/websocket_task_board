Build me an applicaiton that consists of a react client side UI and a spring boot server.  The application is to provide a project board type layout similar to trello.  Users can add columns in which you can add tiles (or postits) to the board.  These postits would have an owner, title, description and possibly attatchments such as images, text files, mark down or pdfs.  Each postit can be repositioned either in its column or moved across columns.  The service should be able to persist this project board.  Further if more than one UI is running changes to one ui should get updated in the other uis.  Postits should be able to have a color also assigned to them.  Data should be persisted in a database.
